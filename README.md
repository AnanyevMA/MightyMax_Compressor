# 🚀 MightyMax Compressor

**MightyMax Compressor** — это мощное локальное веб-приложение для умного сжатия и конвертации изображений.
Оно работает по принципу **TinyPNG**, но полностью оффлайн, гарантируя 100% приватность ваших данных. Никакие фотографии не отправляются на удаленные серверы.

## ✨ Возможности

* **🔒 100% Приватность:** Все происходит на вашем компьютере.
* **🍏 Поддержка iPhone (HEIC):** Автоматически конвертирует `.heic` фотографии в `.jpg` для совместимости.
* **⚡ Умное сжатие:**
    * **PNG:** Адаптивное квантование (уменьшение палитры) + дизеринг.
    * **JPEG:** Оптимизация таблиц Хаффмана, прогрессивное сканирование.
    * **WebP:** Современный формат с максимальной экономией места.
* **🔄 Конвертер форматов:** Преобразуйте PNG/HEIC в JPEG или WebP "на лету".
* **🎛 Настройка качества:** Ползунок для контроля баланса между размером и качеством.
* **📦 Пакетная обработка:** Загружайте сотни файлов сразу и скачивайте результат одним ZIP-архивом.
* **🖥 Кроссплатформенность:** Работает как приложение (`.exe` / `.app`) на Windows и macOS.

## 📥 Как скачать и запустить (Для пользователей)

Вам не нужно устанавливать Python. Просто скачайте готовую программу.

### 🪟 Windows
1. Перейдите во вкладку **Actions** (или Releases, если вы их создали) в этом репозитории.
2. Найдите последнюю успешную сборку (Artifacts).
3. Скачайте файл `MightyMax.exe`.
4. Запустите файл. Браузер откроется автоматически.

### 🍎 macOS
1. Скачайте `MightyMax_Mac.zip` из Artifacts.
2. Распакуйте архив и перенесите `MightyMax.app` в папку **Программы** (Applications) или на Рабочий стол.
3. **Важно:** При первом запуске macOS может заблокировать приложение ("Неизвестный разработчик").
    * Кликните по иконке **Правой кнопкой мыши** -> **Открыть** -> **Открыть**.
    * *Или* выполните в терминале команду для снятия карантина:
        ```bash
        xattr -cr /путь/к/MightyMax.app
        ```

## 🛠 Запуск из исходного кода (Для разработчиков)

Если вы хотите доработать проект, следуйте инструкции:

### 1. Клонирование репозитория
```bash
git clone [https://github.com/ВАШ_НИК/MightyMax.git](https://github.com/ВАШ_НИК/MightyMax.git)
cd MightyMax

2. Создание виртуального окружения
Windows:

PowerShell
python -m venv venv
venv\Scripts\activate
macOS / Linux:

Bash
python3 -m venv venv
source venv/bin/activate
3. Установка зависимостей
Bash
pip install -r requirements.txt
4. Запуск
Bash
python app.py
Сервис будет доступен по адресу: http://127.0.0.1:8000

🏗 Как собрать приложение (Build)
Проект использует PyInstaller для создания исполняемых файлов.

Сборка на Windows (создаст .exe)
PowerShell
pyinstaller --noconsole --onefile --name="MightyMax" --add-data "static;static" app.py
(Обратите внимание на разделитель ;)

Сборка на macOS (создаст .app)
Bash
pyinstaller --noconsole --name="MightyMax" --add-data "static:static" app.py
(Обратите внимание на разделитель :)

Примечание: Для автоматической сборки под macOS используется GitHub Actions (см. .github/workflows/build.yml). Вы не можете собрать macOS-приложение, находясь в Windows.

📂 Структура проекта
app.py — Основной файл (FastAPI сервер, логика сжатия Pillow, конфигурация PyInstaller).

static/ — Фронтенд (HTML, CSS, JS). Вшит в Python-код.

.github/workflows/ — CI/CD скрипты для сборки в облаке.

requirements.txt — Список библиотек.
